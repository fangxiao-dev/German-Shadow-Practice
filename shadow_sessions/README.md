# shadow_sessions

Purpose:
- Store one Markdown session file per capture.
- Session files are intermediate records, not the permanent asset store.

Naming rule:
- Use `YYYY-MM-DD-HHMM.md`.
- Example: `2026-04-13-0930.md`.

File purpose:
- Store the source transcript path plus the staged capture result.
- Record the capture-stage classification, with `Must Keep Candidates` and `Recommendations` using the same item fields.
- Use `collocation` only as subordinate wording attached to a target, not as a separate target.
- Do not use this folder for durable assets or review state.
- Do not duplicate the full raw transcript body here when the source file already exists under `raw-transcripts/`.
